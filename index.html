// Sobre Mim

Analista de Dados com formação em Análise e Desenvolvimento de Sistemas e especialização em Data Analytics e Inteligência Artificial Aplicada a Negócios, foco minha atuação em transformar dados em valor estratégico para a tomada de decisão.

Utilizo Python e as bibliotecas Pandas, Numpy e Matplotlib para o tratamento e manipulação de informações, além de possuir experiência em SQL Server para a gestão e consulta de bancos de dados relacionais.

Complemento minhas entregas com o desenvolvimento de dashboards e visualizações de impacto no Power BI, visando otimizar processos e fornecer insights precisos que facilitem a resolução de problemas de negócio.
