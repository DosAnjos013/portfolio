Automação RPA: Pipeline de Extração e Inteligência

Desenvolvimento de um robô de automação (RPA) para extração mensal de dados de vendas de sistemas legados, eliminando erros manuais e preparando dados para dashboards estratégicos.

Objetivo

Automatizar o processo completo de extração de relatórios mensais de vendas de um sistema legado (ConnectPlug), incluindo login automatizado, navegação no sistema, download de dados, tratamento com Pandas e geração de visualizações analíticas com Matplotlib — tudo em um único pipeline.

Pipeline de Automação

1. Abertura do Navegador

O robô abre o Chrome, acessa o sistema ConnectPlug e verifica o estado de login automaticamente.

2. Login Automatizado

Preenchimento automático de código da empresa, usuário e senha, com verificação de estado de autenticação.

3. Extração de Relatórios

Navegação automatizada até o relatório de vendas, seleção do mês atual, filtro por produtos e download do arquivo Excel.

4. Tratamento de Dados

Leitura do Excel com Pandas, formatação de valores monetários (R$), ordenação por valor e seleção do Top 10 produtos.

5. Análise Visual

Geração automática de mosaico com gráficos de barras: Top 10 por quantidade vendida e Top 10 por faturamento.

6. Exportação

Salvamento do mosaico analítico como imagem PNG em alta resolução (300 DPI) e organização na pasta do projeto.

Destaques Técnicos

  • Uso de PyAutoGUI para controle total da interface gráfica (cliques, digitação, drag-and-drop)
  • Função personalizada arrasta() para simular movimentos de scroll e drag no sistema
  • Detecção automática do mês atual via locale e calendar para gerar relatórios dinâmicos
  • Tratamento robusto de dados financeiros: remoção de "R$", conversão de vírgula para ponto, cast para float
  • Pipeline end-to-end: da extração do dado bruto até a visualização final, sem intervenção humana
  • Uso de PyPerClip para captura de caminhos de arquivo e URLs da área de transferência

Impacto

100% Eliminação de erros manuais na extração de dados
Automático Relatório mensal gerado sem intervenção humana
Top 10 Análise automática dos produtos mais vendidos

Tecnologias Utilizadas

Python PyAutoGUI Pandas Matplotlib PyPerClip Excel / OpenPyXL
