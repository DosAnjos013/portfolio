Clusterização de Clientes para Estratégias de Retenção e Engajamento

Utilizando Python, Pandas e Scikit-learn para segmentar clientes com base em características comportamentais e financeiras, identificando perfis distintos para ações estratégicas direcionadas.

Objetivo

O objetivo deste projeto foi aplicar técnicas de Machine Learning não supervisionado para segmentar a base de clientes em grupos homogêneos, permitindo à empresa direcionar estratégias de retenção e engajamento de forma personalizada e baseada em dados.

Metodologia

1. Pré-processamento

Limpeza, tratamento de valores nulos e normalização dos dados para garantir qualidade na segmentação.

2. Seleção de Features

Identificação e seleção das features comportamentais e financeiras mais relevantes para a clusterização.

3. Determinação de Clusters

Utilização do método Elbow e Silhouette Score para determinar o número ideal de clusters.

4. Análise dos Segmentos

Interpretação e caracterização de cada cluster, identificando padrões de comportamento e necessidades únicas.

Principais Resultados

3 Segmentos de clientes identificados com características únicas
K-Means Algoritmo de clusterização utilizado para segmentação
Personalização Ações estratégicas direcionadas para cada perfil de cliente

Tecnologias Utilizadas

Python Pandas Scikit-learn Matplotlib NumPy
